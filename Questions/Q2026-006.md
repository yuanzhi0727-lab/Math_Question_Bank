### 題目

對任意數列 $a_1, a_2, \dots, a_n$，定義函數 $f$ 如下：

$$
f(a_1, a_2, \dots, a_n) = \begin{cases} a_1 & \text{若 } n = 1 \\ f(a_1 + a_2, a_2 + a_3, \dots, a_{n-1} + a_n) & \text{若 } n \ge 2 \end{cases}
$$

例如：$f(0, 1, 2, 3) = f(1, 3, 5) = f(4, 8) = f(12) = 12$。則 $f(0, 1, 2, \dots, 100)$ 除以 $1000$ 的餘數為 $\underline{\quad 800 \quad}$。 (2026TRML團體賽)

### 答案

800

### 解析

透過 $f(0,1,2,3)$ 會發現 $0,1,2,3$ 分別被用了 $1,3,3,1$ 次  
故可寫成 $0\cdot C^3_0 + 1\cdot C^3_1 + 2\cdot C^3_2 + 3\cdot C^3_3 = \sum\limits^{3}_{k=0} {kC^3_k}  $  
同理，$f(0,1,2,\cdots,100)$ 可以寫成 $\sum\limits^{100}_{k=0}{kC^{100}_k}=100\sum\limits^{100}_{k=1}{kC^{99}_{k-1}}$
