### 題目

已知 $a, b, c, d$ 為正數，且滿足 $abcd = 1$，試證：(111校內學科能力競賽)

$$
\frac{1 + ab}{1 + a} + \frac{1 + bc}{1 + b} + \frac{1 + cd}{1 + c} + \frac{1 + da}{1 + d} \ge 4
$$ 


### 答案

見解析證明。

### 解析

設原式左邊為 $A$：

$$
A = \frac{1 + ab}{1 + a} + \frac{1 + bc}{1 + b} + \frac{1 + cd}{1 + c} + \frac{1 + da}{1 + d}
$$

1. **利用 $abcd = 1$ 進行變數代換：**
   由 $abcd = 1$ 可得 $cd = \frac{1}{ab}$ 與 $da = \frac{1}{bc}$。
   代入後兩項的分母與分子：
   * 第三項：
     $$
     \frac{1 + cd}{1 + c} = \frac{1 + \frac{1}{ab}}{1 + c} = \frac{\frac{ab + 1}{ab}}{\frac{c(ab) + c}{c}} = \frac{1 + ab}{ab(1 + c)} = \frac{1 + ab}{ab + abc}
     $$
   * 第四項：
     $$
     \frac{1 + da}{1 + d} = \frac{1 + \frac{1}{bc}}{1 + d} = \frac{\frac{bc + 1}{bc}}{\frac{d(bc) + d}{d}} = \frac{1 + bc}{bc(1 + d)} = \frac{1 + bc}{bc + bcd}
     $$

2. **重新分組並提出公因式：**
   將第一與第三項、第二與第四項組合：
   $$
   A = \left( \frac{1 + ab}{1 + a} + \frac{1 + ab}{ab + abc} \right) + \left( \frac{1 + bc}{1 + b} + \frac{1 + bc}{bc + bcd} \right)
   $$
   $$
   A = (1 + ab)\left( \frac{1}{1 + a} + \frac{1}{ab + abc} \right) + (1 + bc)\left( \frac{1}{1 + b} + \frac{1}{bc + bcd} \right)
   $$

3. **利用[倒數不等式](https://hackmd.io/@QQPVjgfqQ-mOBOVFbwvwpQ/ByrCDTcFfx)（或算幾不等式/柯西不等式）：**
   對任意正實數 $x, y > 0$，由算幾不等式或柯西不等式可得 $\frac{1}{x} + \frac{1}{y} \ge \frac{4}{x + y}$。
   * 對前項分母取 $x = 1 + a$ 與 $y = ab + abc$：
     $$
     \frac{1}{1 + a} + \frac{1}{ab + abc} \ge \frac{4}{1 + a + ab + abc}
     $$
   * 對後項分母取 $x = 1 + b$ 與 $y = bc + bcd$：
     $$
     \frac{1}{1 + b} + \frac{1}{bc + bcd} \ge \frac{4}{1 + b + bc + bcd}
     $$

4. **代回原式進行化簡：**
   $$
   A \ge (1 + ab)\left( \frac{4}{1 + a + ab + abc} \right) + (1 + bc)\left( \frac{4}{1 + b + bc + bcd} \right)
   $$
   $$
   A \ge 4 \left( \frac{1 + ab}{1 + a + ab + abc} + \frac{1 + bc}{1 + b + bc + bcd} \right)
   $$

   將第二項分式之分子與分母同乘以 $a$：
   * 分子：$a(1 + bc) = a + abc$
   * 分母：$a(1 + b + bc + bcd) = a + ab + abc + abcd = a + ab + abc + 1$ （因為 $abcd = 1$）

   因此兩項具有相同的分母 $(1 + a + ab + abc)$：
   $$
   A \ge 4 \left( \frac{1 + ab}{1 + a + ab + abc} + \frac{a + abc}{1 + a + ab + abc} \right)
   $$
   $$
   A \ge 4 \left( \frac{1 + ab + a + abc}{1 + a + ab + abc} \right) = 4 \times 1 = 4
   $$

故得證 $\frac{1 + ab}{1 + a} + \frac{1 + bc}{1 + b} + \frac{1 + cd}{1 + c} + \frac{1 + da}{1 + d} \ge 4$。
