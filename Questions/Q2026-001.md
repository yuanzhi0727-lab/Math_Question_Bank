# 題目

在 $\triangle ABC$ 中，已知 $\angle A = 60^\circ$，$b = 5$，$c = 8$，求 $a$ 之值。

---

# 解析

利用餘弦定理：
$$a^2 = b^2 + c^2 - 2bc \cos A$$

代入已知條件：
$$a^2 = 5^2 + 8^2 - 2(5)(8) \cos 60^\circ$$
$$a^2 = 25 + 64 - 80 \times \frac{1}{2}$$
$$a^2 = 89 - 40 = 49$$

因為長度取正值，故 $a = 7$。
