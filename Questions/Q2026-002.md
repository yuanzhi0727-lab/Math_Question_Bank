### 題目

滿足方程式

$$
\frac{x^2 - 8x - 15}{x + 7} - \frac{x^2 - 8x - 10}{x + 12} + \frac{x^2 - 8x - 5}{x + 17} = 1
$$

的正實數 $x$ 為 $\underline{\quad 11 \quad}$。 (2026TRML團體賽)

### 解析

### 方法一：多項式除法與變數代換法

**第一步：將各分式進行多項式除法（分離整數部分）**

對各分式的分子進行多項式除法拆解：

1. 第一項：
   $$
   x^2 - 8x - 15 = (x + 7)(x - 15) + 90 \implies \frac{x^2 - 8x - 15}{x + 7} = (x - 15) + \frac{90}{x + 7}
   $$

2. 第二項：
   $$
   x^2 - 8x - 10 = (x + 12)(x - 20) + 230 \implies \frac{x^2 - 8x - 10}{x + 12} = (x - 20) + \frac{230}{x + 12}
   $$

3. 第三項：
   $$
   x^2 - 8x - 5 = (x + 17)(x - 25) + 420 \implies \frac{x^2 - 8x - 5}{x + 17} = (x - 25) + \frac{420}{x + 17}
   $$

**第二步：代回原方程式並整理**

將上述結果代回原式：

$$
\left[ (x - 15) + \frac{90}{x + 7} \right] - \left[ (x - 20) + \frac{230}{x + 12} \right] + \left[ (x - 25) + \frac{420}{x + 17} \right] = 1
$$

化簡一次項與常數項：

$$
(x - 15 - x + 20 + x - 25) + \frac{90}{x + 7} - \frac{230}{x + 12} + \frac{420}{x + 17} = 1
$$

$$
(x - 20) + \frac{90}{x + 7} - \frac{230}{x + 12} + \frac{420}{x + 17} = 1
$$

將 $1$ 移至等號左邊：

$$
(x - 21) + \frac{90}{x + 7} - \frac{230}{x + 12} + \frac{420}{x + 17} = 0
$$

**第三步：平移變數以簡化分母**

觀察分母 $x + 7$, $x + 12$, $x + 17$，令 $y = x + 12$：
- $x + 7 = y - 5$
- $x + 17 = y + 5$
- $x - 21 = y - 33$

方程式轉化為：

$$
(y - 33) + \frac{90}{y - 5} - \frac{230}{y} + \frac{420}{y + 5} = 0
$$

**第四步：通分與因式分解**

將第一項與第四項通分合併：

$$
\frac{90}{y - 5} + \frac{420}{y + 5} = \frac{90(y + 5) + 420(y - 5)}{y^2 - 25} = \frac{510y - 1650}{y^2 - 25} = \frac{30(17y - 55)}{y^2 - 25}
$$

原式變為：

$$
(y - 33) - \frac{230}{y} + \frac{30(17y - 55)}{y^2 - 25} = 0
$$

通分並去分母可得高次多項式：

$$
(y - 23)(y + 2)(y^2 + 24y + 169) = 0
$$

解得：
1. $y = 23 \implies x = y - 12 = 11$
2. $y = -2 \implies x = y - 12 = -14$（非正實數，不合）
3. $y^2 + 24y + 169 = 0 \implies \Delta = 24^2 - 4 \times 169 = 576 - 676 = -100 < 0$（無實數解）

**結論**

故滿足條件的正實數解為 $x = 11$。
