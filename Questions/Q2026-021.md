### 題目

設三角形的三邊長分別為 $a, b, c$，證明：(112校內學科能力競賽)

$$
a^2(b + c - a) + b^2(c + a - b) + c^2(a + b - c) \le 3abc
$$ 

### 答案

見解析證明。

### 解析

【方法一】

要證明 $a^2(b + c - a) + b^2(c + a - b) + c^2(a + b - c) \le 3abc$，我們可以透過展開與項次整理來進行分析：

1. **展開原式左式：**
   $$
   a^2(b + c - a) + b^2(c + a - b) + c^2(a + b - c)
   $$
   $$
   = a^2b + a^2c - a^3 + b^2c + ab^2 - b^3 + ac^2 + bc^2 - c^3
   $$
   $$
   = (a^2b + ab^2 + b^2c + bc^2 + c^2a + ca^2) - (a^3 + b^3 + c^3)
   $$

2. **移項整理不等式：**
   原不等式等價於：
   $$
   (a^2b + ab^2 + b^2c + bc^2 + c^2a + ca^2) - (a^3 + b^3 + c^3) \le 3abc
   $$
   兩邊移項可得：
   $$
   a^3 + b^3 + c^3 + 3abc \ge a^2b + ab^2 + b^2c + bc^2 + c^2a + ca^2
   $$
   或是寫成：
   $$
   a(a - b)(a - c) + b(b - a)(b - c) + c(c - a)(c - b) \ge 0
   $$

3. **[利用舒爾不等式（Schur's Inequality）](https://hackmd.io/@QQPVjgfqQ-mOBOVFbwvwpQ/BkwLgTcFGe)：**

   根據三階舒爾不等式：對於任意非負實數 $a, b, c$ 與正實數 $r$，皆恆成立：
   $$
   a^r(a - b)(a - c) + b^r(b - a)(b - c) + c^r(c - a)(c - b) \ge 0
   $$
   當取 $r = 1$ 時，即為：
   $$
   a(a - b)(a - c) + b(b - a)(b - c) + c(c - a)(c - b) \ge 0
   $$
   展開即得 $a^3 + b^3 + c^3 + 3abc \ge a(b^2 + c^2) + b(c^2 + a^2) + c(a^2 + b^2)$。

4. **結論：**
   因為 $a, b, c$ 為三角形三邊長（皆為正實數），故滿足舒爾不等式的成立條件，等號成立當且僅當 $a = b = c$（即正三角形時）。

故得證 $a^2(b + c - a) + b^2(c + a - b) + c^2(a + b - c) \le 3abc$。  
  
【方法二】  

由於 $a, b, c$ 為三角形的三邊長，根據三角形兩邊之和大於第三邊，可做如下換元：

設：
$$
\begin{cases}
x = \frac{b + c - a}{2} > 0 \\
y = \frac{c + a - b}{2} > 0 \\
z = \frac{a + b - c}{2} > 0
\end{cases}
$$

反解可得：
$$
\begin{cases}
a = y + z \\
b = z + x \\
c = x + y
\end{cases}
$$
其中 $x, y, z$ 皆為正實數。

1. **代入原式左式：**
   原式左邊為：
   $$
   a^2(2x) + b^2(2y) + c^2(2z) = 2 \left[ (y+z)^2 x + (z+x)^2 y + (x+y)^2 z \right]
   $$
   展開括號項：
   $$
   = 2 \left[ (y^2 + 2yz + z^2)x + (z^2 + 2zx + x^2)y + (x^2 + 2xy + y^2)z \right]
   $$
   $$
   = 2 \left[ (xy^2 + xz^2 + yz^2 + yx^2 + zx^2 + zy^2) + 6xyz \right] \quad \text{--- (1)}
   $$

2. **代入原式右式：**
   原式右邊 $3abc$ 為：
   $$
   3(y+z)(z+x)(x+y) = 3 \left[ (xy^2 + xz^2 + yz^2 + yx^2 + zx^2 + zy^2) + 2xyz \right]
   $$
   $$
   = 3(xy^2 + xz^2 + yz^2 + yx^2 + zx^2 + zy^2) + 6xyz \quad \text{--- (2)}
   $$

3. **比較兩式（作差法）：**
   用右式 (2) 減去左式 (1)：
   $$
   \text{右式} - \text{左式} = (xy^2 + xz^2 + yz^2 + yx^2 + zx^2 + zy^2) - 6xyz
   $$

4. **利用算術-幾何平均不等式（AM-GM）：**
   對 $xy^2, xz^2, yz^2, yx^2, zx^2, zy^2$ 這 6 個正實數使用均值不等式：
   $$
   \frac{xy^2 + xz^2 + yz^2 + yx^2 + zx^2 + zy^2}{6} \ge \sqrt[6]{(xy^2)(xz^2)(yz^2)(yx^2)(zx^2)(zy^2)}
   $$
   計算根號內的乘積：
   $$
   (xy^2)(xz^2)(yz^2)(yx^2)(zx^2)(zy^2) = x^6 y^6 z^6
   $$
   因此：
   $$
   \frac{xy^2 + xz^2 + yz^2 + yx^2 + zx^2 + zy^2}{6} \ge \sqrt[6]{x^6 y^6 z^6} = xyz
   $$
   移項可得：
   $$
   xy^2 + xz^2 + yz^2 + yx^2 + zx^2 + zy^2 \ge 6xyz
   $$
   即：
   $$
   \text{右式} - \text{左式} \ge 0 \implies \text{左式} \le \text{右式}
   $$

等號成立條件為 $xy^2 = xz^2 = yz^2 = yx^2 = zx^2 = zy^2$，即 $x = y = z$，對應到原三角形為 $a = b = c$（正三角形）。

故得證 $a^2(b + c - a) + b^2(c + a - b) + c^2(a + b - c) \le 3abc$。
