### 題目

設 $a, b, c > 0$ 且 $abc = 1$，試證明：(114校內學科競賽)

$$
\frac{1}{a + b + 1} + \frac{1}{b + c + 1} + \frac{1}{c + a + 1} \le 1
$$  

### 答案

見解析證明。

### 解析

設 $a = x^3, b = y^3, c = z^3$，因為 $a, b, c > 0$ 且 $abc = 1$，故 $x, y, z > 0$ 且滿足 $xyz = 1$。

1. **第一項之放縮：**
   利用因式分解：
   $$
   a + b + 1 = x^3 + y^3 + 1 = (x + y)(x^2 - xy + y^2) + xyz
   $$
   因為 $(x - y)^2 \ge 0 \implies x^2 + y^2 \ge 2xy \implies x^2 - xy + y^2 \ge xy$，故：
   $$
   a + b + 1 = (x + y)(x^2 - xy + y^2) + xyz \ge (x + y)xy + xyz = xy(x + y + z)
   $$
   倒數放縮可得：
   $$
   \frac{1}{a + b + 1} \le \frac{1}{xy(x + y + z)}
   $$

2. **同理放縮其餘兩項：**
   $$
   \frac{1}{b + c + 1} \le \frac{1}{yz(x + y + z)}
   $$
   $$
   \frac{1}{c + a + 1} \le \frac{1}{zx(x + y + z)}
   $$

3. **三項相加求和：**
   $$
   \frac{1}{a + b + 1} + \frac{1}{b + c + 1} + \frac{1}{c + a + 1} \le \frac{1}{xy(x + y + z)} + \frac{1}{yz(x + y + z)} + \frac{1}{zx(x + y + z)}
   $$
   通分整理分子：
   $$
   = \frac{z + x + y}{xyz(x + y + z)} = \frac{x + y + z}{xyz(x + y + z)} = \frac{1}{xyz}
   $$
   因為 $xyz = 1$，故：
   $$
   \frac{1}{a + b + 1} + \frac{1}{b + c + 1} + \frac{1}{c + a + 1} \le \frac{1}{1} = 1
   $$
   故得證。
