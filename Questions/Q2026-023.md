### 題目

$\Delta ABC$ 中，頂點 $A$、$B$、$C$ 的對邊長分別是 $a$、$b$、$c$[cite: 20]。若 $a^2, b^2, c^2$ 為等差數列，則 $\sqrt{3}\cos B + \sin B$ 的最小值為 $\underline{\quad \sqrt{3} \quad}$。 (2026TRML 個人賽)

### 答案

$\sqrt{3}$

### 解析

1. **利用等差數列性質與餘弦定理：**
   已知 $a^2, b^2, c^2$ 成等差數列[cite: 20]，故其等差中項滿足：
   $$
   a^2 + c^2 = 2b^2
   $$
   根據餘弦定理：
   $$
   \cos B = \frac{a^2 + c^2 - b^2}{2ac}
   $$
   將 $a^2 + c^2 = 2b^2$ 代入餘弦定理分子：
   $$
   \cos B = \frac{2b^2 - b^2}{2ac} = \frac{b^2}{2ac}
   $$

2. **利用算術-幾何平均不等式（AM-GM）求 $\cos B$ 的範圍：**
   由 $a^2 + c^2 = 2b^2$，且對任意正數 $a, c$ 皆滿足 $a^2 + c^2 \ge 2ac$，可得：
   $$
   2b^2 \ge 2ac \implies b^2 \ge ac
   $$
   將 $b^2 \ge ac$ 代回 $\cos B$：
   $$
   \cos B = \frac{b^2}{2ac} \ge \frac{ac}{2ac} = \frac{1}{2}
   $$
   因為 $B$ 為三角形的內角（$0^\circ < B < 180^\circ$），且 $\cos B \ge \frac{1}{2}$，故：
   $$
   0 < B \le 60^\circ \quad \left(\text{即 } 0 < B \le \frac{\pi}{3}\right)
   $$

3. **利用正弦/餘弦疊合公式：**
   將目標式進行疊合：
   $$
   \sqrt{3}\cos B + \sin B = 2\left(\frac{1}{2}\sin B + \frac{\sqrt{3}}{2}\cos B\right) = 2\sin\left(B + 60^\circ\right)
   $$

4. **求角度範圍與極值：**
   因為 $0^\circ < B \le 60^\circ$，所以：
   $$
   60^\circ < B + 60^\circ \le 120^\circ
   $$
   在 $60^\circ < B + 60^\circ \le 120^\circ$ 的區間內，正弦函數 $\sin(B + 60^\circ)$ 的值滿足：
   $$
   \frac{\sqrt{3}}{2} \le \sin(B + 60^\circ) \le 1
   $$
   （當 $B + 60^\circ = 60^\circ$ 或 $120^\circ$ 即 $B \to 0^\circ$ 或 $B = 60^\circ$ 時取得最小值 $\frac{\sqrt{3}}{2}$）。

   因此，原式的最小值為：
   $$
   2 \times \frac{\sqrt{3}}{2} = \sqrt{3}
   $$

故 $\sqrt{3}\cos B + \sin B$ 的最小值為 $\sqrt{3}$。
